# Skills

Each subdirectory here is a category (e.g. `onboarding`, `health-and-ris)`), and each category holds one folder per skill:

```
skills/category-name/skill-name/
├── SKILL.md           # required — YAML frontmatter + instructions body
├── references/        # optional — docs the agent reads on demand
├── scripts/           # optional — deterministic helpers
└── assets/            # optional — templates that end up in the output
```

Category folders aren't created yet — the taxonomy is locked, the `_category.json` files are next up.
